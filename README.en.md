A cross-platform terminal application built with **Tauri V2 + Rust + Vue 3 + shadcn-vue (built on reka-ui)**.

Adapted from the open-source project [Tabby](https://github.com/Eugeny/tabby) (MIT License), with the entire architecture rewritten:

- **Backend**: Rust (Tauri V2) — PTY management / config persistence / shell detection
- **Frontend**: Vue 3 + Vite + Tailwind CSS 4 + shadcn-vue, terminal rendering via xterm.js (WebGL-first)
- **Toolchain**: bun (package manager), oxlint (linting)

## Download & Install

Download the latest version from [GitHub Releases](https://github.com/shawicx/scx-terminal/releases):

| Platform | File | Notes |
| --- | --- | --- |
| Windows | `scx-terminal_<version>_x64-setup.exe` | NSIS installer; UI follows the system language (Chinese/English) |
| macOS (Apple Silicon) | `scx-terminal_<version>_aarch64.dmg` | Drag into Applications to install |
| macOS (Intel) | `scx-terminal_<version>_x64.dmg` | Drag into Applications to install |

### Windows

1. Double-click `*-setup.exe`. If SmartScreen shows "Windows protected your PC", click "More info" → "Run anyway"
2. Choose the install mode as needed: **install for the current user only** (no admin required) or **install for all users** (admin required)
3. Confirm the install directory and finish

### macOS

1. Open the DMG and drag scx-terminal into Applications
2. If first launch reports the developer cannot be verified: right-click scx-terminal in Applications → **Open**, then click "Open" once to confirm; or run in a terminal:
   `xattr -d com.apple.quarantine /Applications/scx-terminal.app`

### Data Directory

| Platform | Path |
| --- | --- |
| Windows | `%APPDATA%\com.scx.terminal\` (config.db / logs\) |
| macOS | `~/Library/Application Support/com.scx.terminal/` |

The "About" page in Settings provides one-click open of these directories and a debug-log toggle.

## Development

```bash
bun install
bun run app:dev
```

Common scripts:

| Command | Description |
| --- | --- |
| `bun run dev` | Start the frontend Vite dev server only |
| `bun run app:dev` | Start the full desktop app (dev mode) |
| `bun run app:build` | Build release installers |
| `bun run lint` | Run oxlint |
| `bun run test` | Run vitest unit tests |

## Project Structure

```
src/          Vue frontend (components / stores / services / lib / i18n)
src-tauri/    Rust backend (PTY backpressure queue / config persistence / shell detection)
```

## Build Artifacts

`bun run app:build` produces `src-tauri/target/release/bundle/macos/scx-terminal.app`
(~10 MB). The DMG is generated by Tauri's beautify script (create-dmg, which requires
Finder/AppleScript permissions); in environments without GUI permissions, fall back
to hdiutil:

```bash
hdiutil create -volname scx-terminal \
  -srcfolder src-tauri/target/release/bundle/macos/scx-terminal.app \
  -ov -format UDZO scx-terminal.dmg
```

## Debugging

- `SCX_DEVTOOLS=1 bun run app:dev` automatically opens the WebView Inspector
- Frontend errors are forwarded to the Rust console (with the `[scx:js]` prefix)

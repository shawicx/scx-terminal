$ 特性

      
每一格都会响应你的指针 —— 就像终端响应每一次按键。


      

        

          

          
WebGL 加速渲染

          
xterm.js WebGL 优先渲染，Canvas 自动降级。大输出、全屏 vim、htop 监控，帧率稳如原生。

          
fps 60 ▮

        


        

          

          
本地 / SSH / Mosh

          
统一会话工厂按配置档案创建会话，本地 shell、远程 SSH、弱网 Mosh 无缝切换。

        


        

          

          
SFTP 文件传输

          
远程会话内直接浏览与传输文件，无需再开一个客户端。

        


        

          

          
端口转发

          
可视化规则管理，本地 / 远程 / 动态转发一键配置。

        


        

          

          
命令面板 + 系统级集成

          
⌘K 唤起命令面板；系统通知、剪贴板、应用内自动更新全部经由 Tauri 官方插件原生接入。

          
› 试试在本页按下 ⌘K

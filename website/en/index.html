$ Features

      
Every cell responds to your pointer — just like a terminal responds to every keystroke.


      

        

          

          
WebGL-accelerated rendering

          
xterm.js with WebGL-first rendering and automatic Canvas fallback. Massive output, fullscreen vim, htop — frame rate stays rock solid.

          
fps 60 ▮

        


        

          

          
Local / SSH / Mosh

          
A unified session factory creates sessions from profiles — local shell, remote SSH, or Mosh on flaky networks.

        


        

          

          
SFTP transfers

          
Browse and transfer files inside remote sessions. No extra client needed.

        


        

          

          
Port forwarding

          
Visual rule management — local, remote and dynamic forwarding in one place.

        


        

          

          
Command palette + native integration

          
Hit ⌘K for the command palette. Notifications, clipboard and in-app auto-updates all flow through official Tauri plugins.

          
› try pressing ⌘K on this page
